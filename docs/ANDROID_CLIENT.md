# Android-клиент HardwareDisplay

Клиент собран как Kotlin + Jetpack Compose приложение в `android/`. Он повторяет правила [PROTOCOL.md](PROTOCOL.md) и экраны [DESIGN.md](DESIGN.md), работает в одной локальной сети и держит одно активное подключение.

## Состав

| Слой | Где | Что делает |
| --- | --- | --- |
| Протокол | `protocol/Frames.kt`, `protocol/Invite.kt`, `protocol/ManualEntry.kt` | Разбор кадров `hello`/`catalog`/`snapshot`, проверка приглашения, сбор приглашения из полей экрана Windows. |
| Сеть | `net/HostTransport.kt`, `net/PinnedTrustManager.kt`, `net/Bearer.kt` | OkHttp с `Proxy.NO_PROXY`, отдельный `Dns` на числовой IPv4 из приглашения, доверие единственному листу по SHA-256, bearer на 256 бит. |
| Сессия | `session/SessionRepository.kt` | Поток WSS, состояния связи, backoff 1→30 с с jitter, сопряжение с проверкой через `GET /v1/session`, отзыв доступа. |
| Каталог по умолчанию | `session/DefaultPresets.kt` | Стартовые пресеты строятся из фактического каталога: «Основное», «Память», «Температуры», «Видеокарта». |
| История | `session/HistoryRecorder.kt` | Пачки раз в 5 с, дедупликация по `(hostId, sensorId, streamEpoch, seq)`, час и 100 000 точек, не больше 24 датчиков. |
| Хранение | `data/AppDatabase.kt`, `data/SettingsStore.kt`, `data/TokenStore.kt` | Room для ПК, пресетов, карточек и истории; DataStore для активного ПК и режима экрана; bearer — AES-GCM с ключом в Android Keystore. |
| Интерфейс | `ui/` | Панель, сравнение, редактор пресетов, подключение, сканер QR, ручной ввод. |

## Что реализовано из правил протокола

- Проверка приглашения: версия 1, UUID в канонической форме, IPv4 только из RFC 1918, порт `1..65535`, 64 шестнадцатеричных символа отпечатка, 32 символа кода, лимит 1024 байта; ссылки и имена хостов не принимаются.
- TLS: собственный `X509TrustManager` принимает один лист, сверяет SHA-256 DER, срок, самоподпись, EKU `serverAuth` и DNS SAN `pc-<hostId>.hardwaredisplay.test`. Любое несовпадение — отказ до отправки токена.
- Сопряжение: `POST /v1/pair` с bearer, ответ `201`; при потере ответа клиент повторяет `GET /v1/session` в 15-секундном окне, при неудаче сохраняет pending и проверяет его по действию пользователя.
- Поток: подпротокол `hardwaredisplay.v1`, `hello` → `catalog` → `snapshot`, снимок без каталога нужной ревизии и смена `streamEpoch` считаются ошибкой потока.
- Состояния: «Подключение», «В эфире», «Нет свежих замеров», «Связь потеряна» с временем последнего замера, «Доступ отозван», «Не удалось подтвердить ПК», «Версия несовместима».
- Переподключение: задержка 1, 2, 4, 8, 16, 30 с с jitter, сброс после устойчивого потока, немедленная попытка по сигналу `ConnectivityManager`; ручная остановка и отказ авторизации повторов не запускают.
- История: разрывы восстанавливаются по разнице `capturedAtUtc`, точки с ненулевым статусом в график и минимумы/максимумы не попадают.
- Каталог кэшируется между запусками, поэтому без связи карточки сохраняют названия датчиков. Последнее значение при этом не сохраняется: после перезапуска без сети показывается состояние связи, а не прошлый замер.

## Интерфейс

- Панель: главная карточка на всю ширину, сетка компактных карточек (в альбомной ориентации — одна колонка справа), строка пресетов, действия «Сравнить» и «Изменить», переключатель «Экран вкл».
- Сравнение: до трёх рядов, окна 5/15/60 минут, общий курсор с касанием и перетаскиванием, минимум и максимум по видимому окну, подпись времени и значения под каждым рядом.
- Редактор: переименование, порядок, замена датчика, переключение вида «число/график», выбор главной карточки и рядов сравнения, сохранение копии и удаление пресета.
- Подключение: сохранённые ПК с переименованием и удалением, подтверждение pending-сопряжения, сканер QR на CameraX и ML Kit, ручной ввод полей или полного приглашения.

## Проверка

Выполнено на эмуляторе Android 17 (API 37) с экраном 1080×2400 при 395 dpi, что соответствует целевому Poco X5 Pro 5G; физическое устройство к машине не подключено.

| Сценарий | Результат |
| --- | --- |
| Сборка и тесты | `assembleDebug` без ошибок, 26 юнит-тестов, lint без ошибок |
| Сопряжение с реальным ПК | ручной ввод приглашения, `201`, панель открылась с живыми CPU и RAM |
| Сохранение между запусками | после переустановки APK ПК и пресет восстановлены, поток поднялся сам |
| Пресеты и редактор | переключение вида карточки на график, сохранение, мини-график на панели |
| Сравнение | три ряда, курсор 09:56:02, значения и минимум/максимум по окну |
| Поворот экрана | портрет и альбомная ориентация без потери сессии |
| Потеря сети | «Связь потеряна» с временем последнего замера, восстановление после возврата сети |
| Отзыв доступа на ПК | «Доступ отозван», повторное сопряжение новым приглашением работает |
| Перезапуск без сети | кэшированный каталог сохраняет названия датчиков |
| Новые датчики хоста | в редакторе видны GPU, VRAM, оба диска и температуры с подписями устройств; карточка GPU добавлена и показывает живые 3,2 % |
| Release-сборка с R8 | 8,0 МБ для arm64 против 41 МБ debug: сериализация протокола и Room пережили минификацию, сопряжение и поток работают |

Снимки экранов: [панель](screenshots/panel.png), [сравнение](screenshots/compare.png), [альбомная ориентация](screenshots/panel-landscape.png), [потеря связи](screenshots/panel-offline.png).

Не проверено: физический Poco X5 Pro 5G, расход батареи, длительная работа под нагрузкой, реальные GPU и температурные датчики, отказ в разрешении камеры на устройстве с MIUI.

## Сборка

```powershell
.\android\gradlew.bat -p android :app:assembleDebug
.\android\gradlew.bat -p android :app:assembleRelease
.\android\gradlew.bat -p android :app:testDebugUnitTest
.\android\gradlew.bat -p android :app:lintDebug
adb install -r android\app\build\outputs\apk\release\app-arm64-v8a-release.apk
```

Release-сборка включает R8, упаковку ресурсов и разделение по ABI: arm64 8,0 МБ, armeabi-v7a 6,4 МБ, x86_64 9,0 МБ (для эмулятора). Подпись пока отладочная — выпускной ключ относится к этапу подготовки сборок.

Нужен JDK 17+ (использован JBR из Android Studio), Android SDK с платформой 37 и build-tools. Проект открывается в Android Studio как каталог `android/`.
